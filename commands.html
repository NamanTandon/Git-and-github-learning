• git init : initializes a new git repository.
      git add filename : add file to git.
      git add . : adds all files to git.
      git commit -m "message" : commits the changes with a message.
      git reset --hard "commit id": lets you move to previous commit version and removes the last commit as well.
      git reset --soft "commit id" " lets you move to previous but doesn't removes the last commit as well.
      git log : provides you all commits with their commit ids.
      git status : lets you know the status of file in git wheteher its commited or added or untracked like that.
      git pull : helps you pull changes from github repo.
      git clone git repo url : helps you clone github repo your local system.
      git branch branch_name : creates a new branch.
      git checkout branch_name : switches to a different branch.
      git merge branch_name : merges a branch into the current branch.
